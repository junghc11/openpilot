# Carrot External AI Android client

- [한국어 설치·연결 안내](README.ko.md)
- [English installation and pairing guide](README.en.md)

This experimental client uses an Android phone to run YOLO through full-graph Qualcomm QNN/HTP when available, then NNAPI or CPU fallbacks. Results remain visualization-only and are not sent to steering, acceleration, braking, radar, Panda, or the safety model.
